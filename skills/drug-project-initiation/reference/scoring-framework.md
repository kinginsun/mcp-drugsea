# 三概率打分框架

## 为什么要拆成三个

「能不能仿」压成一个总分会掩盖最致命的情形：技术上完全可行、法规路径通畅、
但化合物专利还有数年才到期。这种品种的单一总分会落在中间区间，看起来「可以做」，
实际上现在投产等于违约或侵权。

拆开后结论变得可执行：

```
P1 高 + P2 低         → 卡位：研发先行，商业化按到期日后置
P1 高 + P2 高 + P3 低  → 做了也不赚：让给成本更低的对手
P1 低                 → 不必讨论后两项
```

## 维度评分标尺

打分是有依据的判断，不是随手给数。每个分数都要能在报告正文里找到对应证据。

### 法规与参比（15%）

| 区间 | 判据 |
|---|---|
| 90+ | 有国内上市原研进口参比、剂型为常释口服、BE 路径已被行业大规模跑通 |
| 70–90 | 参比明确但仅「境外未进口」，或剂型需额外论证 |
| 40–70 | 参比未公示，或需自行论证参比可得性 |
| <40 | 无参比、路径不明 |

扣分项举例：说明书库为空、目录集无收录 → 从 95 降到 92 档。

### CMC 与 BE（15%）

| 区间 | 判据 |
|---|---|
| 90+ | 原料多家可选且已过评、溶出与处方信息公开充分 |
| 70–90 | 原料登记充足但全部未与制剂共同审评；BCS/溶出无公开依据 |
| 40–70 | 原料来源单一或需自建合成路线 |
| <40 | 高难剂型、无原料来源 |

### 专利（30%，即 P2）

| 区间 | 判据 |
|---|---|
| 80+ | 无有效阻挡专利，或化合物专利已到期 |
| 60–80 | 化合物专利即将到期，仅剩弱阻挡（晶型/工艺）专利 |
| 30–60 | 4.1/4.2 类挑战路线，分值已内含失败概率与诉讼成本折价 |
| <30 | 化合物专利有效且己方采 3 类声明（自我承诺到期前不上市） |

**采 3 类声明即等于承诺不销售，此时 P2 必须取低值。** 不要因为「大家都在申报」
就把该维度调高——申报热度属于竞争窗口维度，不属于专利维度。

### 竞争窗口（15%）

按真实排队规模评，含 BE 登记而非只算已进审评企业。首仿位次被占、队列仍在扩大、
同类老药已深度集采 → 取 20–35 档。

### 市场准入（20%）

医保身份、挂网覆盖省份、终端价格天花板三者合议。有谈判目录身份且已多省挂网执行
是加分项（通道已通，无需从零教育市场）；但公示价同时就是未来仿制药的价格上限，
且协议到期后的续约谈判可能继续下压——两个方向都要计入。

### 时间匹配（5%）

批文预计取得时间与合法上市窗口的错配程度。错配四五年 → 25–30 档；对齐 → 70+。

## 合成与决策带

```
P1 = 法规×0.5 + CMC×0.5
P2 = 专利
P3 = 竞争×0.4 + 市场×0.5 + 时间×0.1
立项综合 = 0.25×P1 + 0.40×P2 + 0.35×P3
```

| 综合分 | 附加条件 | 结论 |
|---|---|---|
| ≥ 70 | 且 P2 ≥ 60 | 建议立项，按专利到期日排产 |
| 45–70 | 或 P2 < 40 但 P1 很高 | 跟踪 / 卡位 |
| < 45 | 或 P2 < 25 且无可靠 4.2 类依据 | 暂缓 |

## 情景分析

至少三个，且 P1 在各情景间通常不变（法规与技术条件不随专利结论变化）：

1. **基准**：采 3 类声明，专利到期前不上市
2. **专利到期后上市**：专利维度升至 70–80，时间匹配显著改善，但竞争窗口进一步恶化
3. **4.1 类挑战成功**：专利维度取中间值（含失败折价），市场准入因提前进入而下调

## 算例（多替诺雷片，2026-09）

| 维度 | 权重 | 基准 | 到期后 | 4.1 成功 |
|---|---|---|---|---|
| 法规与参比 | 15% | 92 | 92 | 92 |
| CMC 与 BE | 15% | 82 | 82 | 82 |
| 专利 | 30% | 18 | 76 | 50 |
| 竞争窗口 | 15% | 32 | 22 | 28 |
| 市场准入 | 20% | 63 | 66 | 55 |
| 时间匹配 | 5% | 28 | 72 | 60 |
| **P1** | | **87** | 87 | 87 |
| **P2** | | **18** | 76 | 50 |
| **P3** | | **47** | 49 | 45 |
| **立项综合** | | **45** | **69** | **57** |

验算：`P3 基准 = 32×0.4 + 63×0.5 + 28×0.1 = 12.8 + 31.5 + 2.8 = 47.1`；
`综合 = 0.25×87 + 0.40×18 + 0.35×47 = 21.75 + 7.2 + 16.45 = 45.4`。

结论：三个情景都没进立项区间。最接近的是到期后情景（69 分，距 70 分线差 1 分），
定性为卡位立项上沿。**敏感性**：专利权重 30%，每变动 10 分带动综合分 4 分；
市场准入权重 20%，变动 10 分只带动 1.8 分。所以跟踪工作应集中在专利结论而非价格。

## 常见错误

- 加权算错。写完表格务必重算 P3 与综合分，这是最高频且最致命的错误。
- 把申报热度当成市场吸引力，错误抬高专利维度或市场准入维度。
- 只用已进审评企业数评估竞争，低估真实队列。
- 用挂网价直接推算仿制药收入，忽略它是上限而非预期成交价。
- 情景之间改动了 P1。除非法规或技术条件真的变了，P1 应保持一致。
